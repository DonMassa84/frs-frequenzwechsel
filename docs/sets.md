# FRS Frequenzwechsel – Sets

## Set 01 – Ankommen

Warm, offen und melodisch. Für Sendungsbeginn oder einen ruhigen Einstieg.

## Set 02 – House/Electro

Mehr Groove und klare Tanzfläche. Geeignet für den ersten Hauptblock.

## Set 03 – Nachtfahrt

Techno, Psy- und Trance-Anteile mit zunehmender Dichte. Für den späten Hauptblock.

## Set 04 – Peak Time

Kurzer, druckvoller Abschlussblock. Kann als Finale oder als Übergang in eine längere DJ-Mix-Strecke laufen.

Die Sets verwenden die lokal kopierten Audiodateien in `sendung_01/audio`. Vor einer öffentlichen Ausstrahlung müssen Rechte und Musikmeldung beim FRS geprüft werden.
